## Функции, реализуемые сервером:

    - Аутентификация пользователя (handleAuth):
        Проверяет, существует ли пользователь с заданным логином и паролем в базе данных. Ответ от сервера зависит от результата — если аутентификация успешна, сервер отправляет подтверждение с логином пользователя, иначе — сообщение об ошибке.
    - Регистрация нового пользователя (handleReg):
        Регистрация нового пользователя с логином, паролем и email. Если email некорректен, сервер отправляет ошибку. В противном случае, если регистрация успешна, сервер отправляет сообщение с подтверждением, иначе — с ошибкой.
    - Получение статистики по поездкам (handleStat):
        Сервер возвращает информацию о поездках пользователя, если такие данные имеются.
    - Проверка ответа на задание (handleCheck):
        Обрабатывает проверку правильности ответа пользователя на задание (сейчас там стоит заглушка).
    - Добавление поездки (handleTrip):
        Создаёт новую поездку, добавляя её в базу данных, если все параметры корректны.
    - Оценка поездки (handleRating):
        Сохраняет оценку для конкретной поездки.
    - Добавление отзыва (handleReview):
        Сохраняет отзыв для конкретной поездки.
    - Поиск поездок (handleFindTrip):
        Обрабатывает запросы на поиск доступных поездок на основе пунктов отправления и назначения.
    - Бронирование поездки (handleBookTrip):
        Обрабатывает запросы на бронирование поездки, проверяя, доступна ли поездка для бронирования.

## Протокол взаимодействия клиента и сервера.
Протокол общения между клиентом и сервером в приложении основан на отправке и получении строковых сообщений через сокеты. Каждое сообщение начинается с ключевого слова, которое указывает на тип операции, заканчивается символом новой строки \r\n.
Формат сообщений состоит из ключевого слова (например, auth, reg и т.д.), за которым следует список параметров, разделённых символом &.
Сервер отправляет ответ, который обычно включает в себя статус выполнения операции:

        auth+&login — успешная аутентификация, где login — это логин пользователя.

        auth- — ошибка аутентификации.

        reg+&login — успешная регистрация, где login — это логин пользователя.

        reg- — ошибка регистрации.

        stat&from$to$time& — информация о поездках.

        stat- — ошибка запроса статистики.

        find+&tripId$driverLogin$driverEmail$time& — найденные поездки.

        find- — нет доступных поездок.

        book+ — успешное бронирование.

        book- — ошибка бронирования.

        rating+ — успешное добавление рейтинга.

        rating- — ошибка добавления рейтинга.
